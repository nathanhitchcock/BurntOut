# BurntOut

Welcome to the official documentation for **BurntOut**, a game about managing stress, leadership, and teamwork while surviving the corporate grind.

## What is BurntOut?

BurntOut is a strategy game where you balance leadership points, manage teammates, and defend against stress using creative tools like coffee machines and standing desks.

Explore the documentation to learn more about the game mechanics, development process, and frequently asked questions.
